#AI Prompt Improver Frontend

A React + TypeScript + Tailwind + Framer Motion frontend for transforming vague website ideas into structured, actionable website briefs. Works with the Node + Express backend that connects to the Gemini API.

Features

User-friendly hero section for entering a website idea

Live character count on textarea (200-character limit)

“Generate Brief” button triggers API call

Smooth animations for results using Framer Motion

Copy brief to clipboard and reset functionality

Example prompt buttons for quick testing

Responsive design

#Tech Stack

React with TypeScript

Tailwind CSS

Framer Motion for animations

Lucide React icons

#Getting Started Prerequisites

Node.js >= 18

npm or yarn

Backend API running (Node + Express with Gemini API)

Installation

Clone the repo:

git clone https://github.com/your-username/ai-prompt-frontend.git
cd ai-prompt-frontend


#Install dependencies:

npm install
## or
yarn install

Running the frontend
npm run dev
